# Moe Counter

多种风格可选的萌萌访客计数器。

## 使用说明

安装后可通过 1Panel 映射的 HTTP 端口访问 Moe Counter。应用数据默认持久化到 `./data`，包括 SQLite 数据库文件。

可选配置 Google Analytics 时，在应用设置中填写 `GA_ID`。
